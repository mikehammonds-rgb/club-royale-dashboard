## How to use this doc
This is the offer-code list from the last check. The same offer code can appear twice (meaning it's usable twice,
not that it's a different offer). To check for changes: pull the current list of offer codes from the site and
compare against the list below, respecting duplicate counts. Flag as NEW any code appearing MORE times than here
or not present here at all — and flag as REMOVED any code here that appears FEWER times, or not at all, on the
live page. Also re-check each offer's "Offer details" panel for bonus Free Play terms — those aren't always shown
on the main offer tile. **And check whether any previously-removed offer has come back** — it happened for the
first time on Aug 23, 2026 (see refresh log below), so it's a real possibility, not just additions/removals.
